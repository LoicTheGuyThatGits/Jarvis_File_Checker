    Self-check

    Tries each part of Jarvis that depends on this PC (the AI model, reading the screen, mouse and keyboard, Wi-Fi, file search, document editing…) and the newer features (Autopilot's model and graphics card, the Jarvis browser, recording, public transport, Classroom, the study coach, memory, calls), and says what works.     Debug mode
    
        
    Shows what Jarvis did for each reply, folded under it: which built-in command caught the message, what Smart commands asked the model, every tool and connected (MCP) tool that ran with its result and time, web pages and documents read, the model's thinking (for models that think, such as qwen3 or deepseek-r1), the full instructions sent and its raw answer.       Compare models
      
        
      Ask several local models the same questions, with the instructions Jarvis gives them in chat, to see which is faster and which answers better before you switch, or after training one. Each answer is checked automatically (Jarvis's manner, the right fact, French answered in French, PC requests turned into the right action, code in a code block), and you can pick the best answer to each question yourself, without seeing which model wrote it. “My own questions” takes your last ten messages from the training log (it stays on this PC).         Smart commands (experimental)

        Connected tools (MCP)
        
        
        Let Jarvis use tools from other programs that speak MCP (the Model Context Protocol): GitHub, Notion, a folder of files, web fetching, maps and many more. A server is either a command Jarvis starts on this PC (many need Node.js for npx or uv for uvx), or a web address with a token in its headers (servers that need a browser sign-in are not supported yet). When your message names a server (“on GitHub, list my open issues”), Jarvis can pick its tools, even with Smart commands off. Every call shows an approval card with the details unless you tick “without asking” for that tool. What a tool returns is treated as data, never as instructions. Tokens are kept in data\mcp.json on this PC only.

          Computer control
          Autopilot: how Jarvis sees your screen and works on it.
          
      
          
        
          Computer control
          
        
          How Autopilot sees and works on this PC. Besides the screenshot, Jarvis reads the open windows, the controls Windows reports and all the text on the screen (Windows' own OCR), so it can click things by name and number instead of guessing positions. A model that cannot see pictures can still work from that text alone. Stop it at any time with the Stop button or Ctrl+Shift+F10.
          
        
        
          
        
        
        
        
        
          
        
        
          Autopilot's model
          
        
          Autopilot works best with a model trained to look at screens. On this PC, qwen3-vl:8b-instruct is the one to use: it runs on an 8 GB graphics card (such as an RTX 4060), reads small text well and points at things precisely. It is a 6.2 GB download and needs Ollama 0.12.7 or newer. Not the plain qwen3-vl:8b: that is the “thinking” version, which thinks for minutes before every step. When it is installed, Autopilot uses it by itself; your chat model stays as it is.
          
        
          
        
          
        
          
        
        
          The Jarvis browser
          
        
          For websites, Autopilot uses a browser window of its own (Edge or Chrome, with its own profile, so it is not signed in to your accounts unless you sign in there yourself). It reads each page as a list of links, buttons and boxes and uses them exactly, instead of clicking spots on a picture. It never types into password boxes.
          
        
        
          
        
          
        
          What Autopilot learned
          
        
          When Autopilot finishes a task, it keeps the steps that worked, and uses them as a guide the next time you ask for something similar. Delete any you do not want it to reuse.
          
        
        
            
        
            Show Autopilot how
            
        
            Do a task once yourself while Jarvis watches, and Autopilot does it your way the next time you ask. Write what you are going to show, press Start, then do it as you normally would in the other windows. Jarvis notes where you click (the button or box under the mouse), what you type and the shortcuts you press. Typing in password boxes, or in windows about passwords or private browsing, is never kept. Press Ctrl+Shift+F9 when you are done. In chat: “watch me export a report as a PDF”, then “stop recording”.
            
        
            
        
            
        
            
        
              
        
              Screen awareness
              
        
              When it is on, Jarvis keeps a quiet eye on your screen, so you can just ask “what does this error mean?”, “help me with this” or “what was that website I had open earlier?”. Every so often, when the screen has changed, it notes the window in front and reads the text on the screen (on this PC). It keeps only the last minutes, in memory: nothing is written to disk or sent anywhere except with your question to your AI model, and it is gone when Jarvis closes. Windows about passwords, private or incognito browsing, and the apps you list below are never read, nor is anything while Autopilot works. It only answers questions asked at the PC, never from the phone or Telegram. In chat: “pause screen awareness”, “stop looking at my screen”, “start screen awareness”.

Each file it changes is backed up first in data\file-backups\projects. It never writes programs or scripts Windows runs by double-click (.exe, .bat, .ps1…) and cannot reach anything outside these folders.

                              Google Classroom
                              
        
                              Optional, if your school allows it: assignments from Google Classroom come in as homework by themselves, and the ones you hand in there are ticked off here. Jarvis only reads your classes and assignments; it never hands in or changes anything. Setup, once: (1) on console.cloud.google.com create a project (free) and turn on the Google Classroom API (APIs & Services > Library); (2) under OAuth consent screen choose External, add your school address as a test user, then press Publish app so the sign-in does not expire after 7 days; (3) under Credentials create an OAuth client ID of type Desktop app; (4) paste its client ID and secret here, press Connect and sign in with your school account.
                              
        
                              Schools decide which apps may read their Google accounts, and many do not allow it for students. If yours does not, Google says so on the sign-in page (and may offer to ask the school's IT). Also: “show my revision plan”, “skip today's revision”, “replan my revision”, “weekly overview”.

Importing adds chats and never replaces existing ones.
                                                  
      
                                                  
    
                                                  
    
                                                  
      
                                                  Memory & documents
                                                  What Jarvis remembers about you, and the documents it can read.
                                                  
      
                                                  
        
                                                  Long-term memory
                                                  
        
                                                  
        
                                                    
        
        
                                                    You can also say “remember that my printer is the HP in the office”, “what do you remember?” or “forget the printer”. Memories are kept in memory.json next to server.py and sent with every request, so keep them short.
                                                    
      
                                                    
      
                                                    
        
                                                    Memory between chats
                                                    
        
                                                    Jarvis keeps a history of your chats on this PC (from the app, the phone, Telegram and calls) so a new chat can pick up where an old one left off: ask “what was that game Luca recommended?” or “when did I talk about the ski trip?”, or “search my chats for Outer Wilds”. It also picks up facts about you as you talk (people, likes, plans, recommendations) and lists them above, marked learned: correct or delete any of them. Passwords, codes, numbers, addresses, health and money are never kept. Learning happens when you are not waiting for an answer. In chat: “what have you learned about me?”, “forget what I said about Luca”, “stop learning from my chats”.
                                                    
        
        
        
                                                    
        
                                                    
        
                                                    
        
                                                      
        
      
                                                      
      
                                                      
        
                                                      Documents
                                                      
        
                                                        
        
        
        
                                                        Files are read on this PC. Only the few passages that match your question go to the local Ollama model; nothing is sent to a cloud provider. PDF, Word, Excel, PowerPoint, CSV, text, Markdown and code files work. You can also drop files onto the chat. To change one, just ask in the chat (“fix the spelling in essay.docx”, “in budget.xlsx replace 2025 with 2026”): you get a new file and the original stays as it is. For that the whole document goes to your chosen AI model, so with a cloud model it is sent to that provider.
                                                        
      
                                                        
    
                                                        
    
                                                        
      
                                                        Notes
                                                        Your notes, which Jarvis can search and quiz you on.
                                                        
      
                                                        
        
                                                        Notes
                                                        
        
                                                        Say “note that the exam is in room 204” and later “what did I note about the exam?”. Notes stay on this PC. For things Jarvis should always know about you, say “remember that …” instead (Memory).
                                                        
        
                                                        
        
                                                        
        
                                                          
        
                                                          
      
                                                          
    
                                                          
    
                                                          
      
                                                          PC & network
                                                          The health of this PC, and your Wi-Fi and network.
                                                          
      
                                                          
        
                                                          PC health
                                                          
        
                                                          Checks disk space, memory, how long the PC has been on, temp files, startup programs and the heaviest programs. You can also ask “how's my PC?”. Say “clean up my temp files” to delete old ones (Jarvis asks you to confirm; it only touches temp files older than 3 days).
                                                          
        
                                                          
        
                                                          
      
                                                          
      
                                                          
        
                                                          Wi-Fi and network
                                                          
        
                                                          See which devices are on your home network and find out why the connection is slow: signal, delay to the router and to the internet, crowded channel, and what this PC itself is using. A PC cannot see how much data other devices use; only the router knows that. In chat: “what devices are on my wifi”, “why is my wifi slow”.
